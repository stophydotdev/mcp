# Stophy MCP

Give your agents the live web. One API to search the web, read what people say, and look up products, places, jobs and homes.

Connect your MCP client to `https://mcp.stophy.dev/mcp` and sign in when it opens the browser. The source and the setup guide for each client are in [stophydotdev/stophy](https://github.com/stophydotdev/stophy/tree/main/mcp).
