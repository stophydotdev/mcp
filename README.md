# Stophy MCP

**Search, read, and act on the web.**

An agent that needs the live web usually needs a search tool, a scraper and a browser, each with its own key, bill and failure modes. Stophy is one API, one key and one prepaid balance for all three, and this MCP server gives your client all of them. You pay per call. Reading a page costs $1 per 1,000, and there are no plans.

- **Search** the web, news, images, papers and YouTube in one call.
- **Read any page** as Markdown, HTML, links, a screenshot or JSON.
- **Crawl and map** a site's URLs, or read the whole site in the background.
- **Extract** the fields you name, each checked against the page.
- **Site parsers** return structured data from Amazon, Reddit, LinkedIn, Google Maps and more.
- **Cloud browser and tasks** run a real browser that fills forms and clicks through a site for you.

## Connect

Use `https://mcp.stophy.dev/mcp` in a client that supports remote MCP, and sign in when it opens the browser. [Remote setup](https://docs.stophy.dev/install-mcp)

For a client that starts a local server, run `stophy mcp`. The source and the setup guide for each client are in [stophydotdev/stophy](https://github.com/stophydotdev/stophy/tree/main/mcp).
