# Stophy MCP

An agent that needs the live web usually needs a search tool, a scraper and a browser tool, each from a different server with its own key and bill. Stophy's MCP server gives your client all of them behind one sign-in.

- **Search** the web, news, images, papers and YouTube.
- **Read any page** as Markdown, HTML, links, a screenshot or JSON.
- **Crawl and map** a whole site, or watch pages for changes.
- **Extract** the fields you name from one page or many.
- **Site parsers** return structured data from Amazon, Reddit, LinkedIn, Google Maps and more.
- **Cloud browser and tasks** run sessions that you drive with code or a prompt.

Connect your MCP client to `https://mcp.stophy.dev/mcp` and sign in when it opens the browser. The source and the setup guide for each client are in [stophydotdev/stophy](https://github.com/stophydotdev/stophy/tree/main/mcp).
